# 여기에 음원을 넣으십시오

이 폴더에 `.mp3` 를 넣어두면 릴스에 그 소리가 깔립니다.
여러 개 넣으면 날마다 돌아가며 쓰입니다. 비어 있으면 무음으로 나갑니다.

## 왜 직접 넣어야 하나

인스타 API 로는 **트렌딩 오디오를 붙일 수 없습니다.** 붙는 것은 MP4 안에
들어 있는 소리뿐입니다. 그래서 자유롭게 쓸 수 있는 음원을 미리 넣어둡니다.

## 어디서 받나 (전부 무료·상업적 이용 가능)

- **Pixabay Music** — https://pixabay.com/music/  (가입 없이 받아집니다)
- **Free Music Archive** — https://freemusicarchive.org/  (CC0 / CC BY 만 고르십시오)
- **YouTube 오디오 보관함** — 유튜브 스튜디오 안, 저작자 표시 없는 곡

30초~1분짜리 잔잔한 곡이면 충분합니다. 영상이 11초라 앞부분만 쓰이고,
짧으면 이어 붙여 채웁니다.

## 주의

- **CC BY 곡을 쓰시면 캡션에 작곡가를 밝히셔야 합니다.** 표기가 필요 없는
  CC0 곡을 쓰시는 편이 관리가 편합니다.
- 유행가·상업 음원은 넣지 마십시오. 인스타가 소리를 지우거나 게시물을 내립니다.
