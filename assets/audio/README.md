# 릴스에 깔리는 음원

이 폴더의 소리 파일이 릴스에 깔립니다. `.mp3` `.m4a` `.aac` `.wav` 를 받습니다.
여러 개 있으면 날짜와 슬롯에 따라 돌아가며 쓰입니다 — 같은 날 세 편이 서로 다른 곡입니다.
폴더가 비면 무음으로 나갑니다.

## 지금 들어 있는 것

계정 주인이 Suno 유료 구독 중에 직접 만든 곡 10개입니다. 권리가 본인에게 있으므로
캡션에 표기할 의무가 없고, 인스타 지문 대조에 걸릴 일도 없습니다.

원본을 구할 수 없어(구글 계정 정지) 본인이 올린 유튜브 영상에서 소리만 받아
왔습니다. 유튜브가 한 번 압축한 것이라 원본보다 음질이 낮습니다.
**Suno 에 다시 들어가실 수 있게 되면 원본을 받아 같은 이름으로 덮어쓰십시오.**

## 왜 직접 넣어야 하나

인스타 API 로는 **트렌딩 오디오를 붙일 수 없습니다.** 붙는 것은 MP4 안에 구워진
소리뿐입니다. 그래서 쓸 권리가 확실한 음원을 미리 넣어둡니다.

## 파이프라인이 알아서 하는 것

- **소리 크기** — 곡마다 녹음 크기가 제각각이라 -14 LUFS 로 맞춥니다.
  인스타·유튜브가 쓰는 기준값이라 앱이 다시 손대지 않습니다.
- **시작 지점** — 곡 앞머리는 대개 조용한 도입부입니다. 실측해 보니 처음 17초가
  45초 지점보다 최대 11dB 낮았습니다. 그래서 30~75초 사이에서 시작합니다.
  시작점은 날마다 옮겨서 같은 곡이 두 번 걸려도 같은 구간이 나오지 않습니다.
- **앞뒤 페이드** — 갑자기 시작하고 뚝 끊기면 귀에 거슬립니다.

## 곡을 더 넣으실 때

가장 안전한 것은 **직접 만드신 곡**입니다. 그 다음이 CC0(퍼블릭 도메인)입니다.

| | 표기 의무 | |
|---|---|---|
| 직접 만든 곡 | 없음 | 가장 좋습니다 |
| CC0 · 퍼블릭 도메인 | 없음 | 관리가 편합니다 |
| CC BY | **있음** | 캡션에 작곡가를 적어야 합니다. 지금 캡션에는 음악 출처 줄이 없으므로, 이 계열을 쓰시려면 파이프라인을 고쳐야 합니다 |

받을 곳: **Pixabay Music** (https://pixabay.com/music/), **Free Music Archive**
(https://freemusicarchive.org/ — CC0 나 CC BY 로 걸러서).

## 넣으면 안 되는 것

- **유행가·상업 음원.** 인스타가 소리를 지우거나 게시물을 내립니다. 반복되면 계정이
  정지됩니다. @sportsnewsstation 은 프로페셔널 계정이라, 앱 안에서 개인 계정이 쓰는
  음악 라이브러리도 대부분 잠겨 있습니다.
- **"Royalty-free" 라고 적힌 유료 음원.** 무료라는 뜻이 아닙니다. 쓸 때마다 사용료를
  따로 내지 않아도 된다는 뜻이지, 라이선스를 사지 않아도 된다는 뜻이 아닙니다.
- **유튜브 오디오 보관함.** 그 라이선스는 유튜브에 올리는 것을 전제로 합니다.
  인스타에 쓰는 것이 명확히 허용되지 않은 곡이 섞여 있습니다.
- **유통사를 통해 발매한 곡.** 본인 곡이어도 Content ID 에 등록되어 있으면 인스타가
  남의 것으로 잡아 음소거합니다.
