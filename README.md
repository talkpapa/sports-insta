## 하루가 어떻게 도는가

```
아침 9시                        12:30       18:30       21:30
──────────────                  ────────────────────────────
뉴스 4개 매체에서 수집            릴스 하나씩 게시
   ↓                              ↓
원고 3장 + 캡션 (Gemini)         게시 전 검사 → 통과해야 올라감
   ↓                              ↓
사진 구하기                      나간 슬롯은 _done 으로
   ↓
1080×1920 카드 3장
   ↓
11초 릴스 영상 (ffmpeg)
   ↓
커밋 → Pages 에 영상 게시
```

**아침 9시에 만드는 이유** — 미국·유럽 경기가 우리 새벽에 끝납니다. 아침이면 그 소식이
이미 RSS에 올라와 있습니다.

**점심부터 올리는 이유** — 영상이 GitHub Pages에 반영되기까지 몇 분 걸립니다.
만들자마자 올리면 인스타가 아직 없는 주소를 가지러 갔다 실패합니다.

## 알고 계셔야 할 제약 세 가지

### ① 트렌딩 오디오를 붙일 수 없습니다

메타 문서를 확인했습니다. 릴스 컨테이너가 받는 건 `video_url`과 `caption`뿐이고,
인스타 라이선스 음원을 붙이는 파라미터가 **없습니다.**

**자동 게시된 릴스는 MP4에 직접 넣은 소리만 나갑니다.** `assets/audio/` 에 자유 이용
음원을 넣어두면 그것이 깔리고, 비어 있으면 무음으로 나갑니다. 넣는 법은 그 폴더의
README를 보십시오.

> 트렌딩 오디오는 릴스 도달의 큰 축입니다. 그것까지 원하시면 **반자동**으로 돌리셔야
> 합니다 — 파이프라인이 영상까지 만들고, 앱에서 오디오만 얹어 올리는 방식입니다.

### ② 현대 스포츠 사진은 자유 라이선스로 거의 없습니다

통신사(AP·게티·연합) 소유이기 때문입니다. 그래서 이 파이프라인은 **선수 얼굴이 아니라
장면**을 씁니다 — 경기장, 잔디, 관중석, 장비. 실존 인물을 암시하지 않으므로 초상권
문제도 없습니다.

`libraryofcongress` 같은 자료 보관소는 걸러냅니다. 100년 된 흑백 사진이 오늘 뉴스
옆에 붙으면 계정이 통째로 이상해 보이기 때문입니다.

**Pexels 무료 키를 넣으면 사진이 더 좋아집니다.** 없어도 돕니다.

### ③ 기사 문장을 옮기지 않습니다

RSS로 받는 것은 제목과 두어 줄 요약뿐이고, 그것으로 "무슨 일이 있었나"만 파악한 뒤
문장은 처음부터 새로 씁니다. 사실은 남의 것이 아니지만 문장은 남의 것입니다.

사망·사고·범죄·소송처럼 가볍게 다루면 안 되는 소재는 원고 단계에서 **스스로 건너뜁니다.**

## 게시 전에 무엇을 검사하는가

사람이 안 보고 나가므로, **조금이라도 이상하면 올리지 않습니다.**

| 검사 | 걸리면 |
|---|---|
| 오늘 몫(3편)을 이미 채웠는가 | 중단 |
| 같은 슬롯을 두 번 올리려는가 | 중단 |
| 직전 게시와 1.5시간 이상 떨어졌는가 | 중단 |
| 캡션이 2,200자 안인가 | 중단 |
| 해시태그가 30개 안인가 | 중단 |
| 캡션에 `undefined`·`NaN` 이 박혀 있는가 | **중단** |
| 사진 출처(📷)가 캡션에 있는가 | 중단 — CC BY는 표기가 의무입니다 |
| 영상 주소가 실제로 열리는가 | 중단 — Pages 반영이 늦으면 여기서 걸립니다 |
| 길이가 3~900초인가 | 중단 |
| 자료가 오늘·어제 것인가 | 중단 |

## 필요한 키

| 이름 | 어디서 | 필수 | 비용 |
|---|---|---|---|
| `GEMINI_API_KEY` | https://aistudio.google.com/apikey | **필수** | 무료 |
| `IG_TOKEN` | developers.facebook.com | **필수** | 무료 |
| `PEXELS_KEY` | https://www.pexels.com/api/ | 선택 | 무료 |

두 곳에 넣으십시오:

- **GitHub 시크릿** — 자동 운전용 · [바로가기](https://github.com/talkpapa/sports-insta/settings/secrets/actions)
- **로컬 `.env`** — 손으로 시험하실 때 (`.env.example` 을 복사해 쓰십시오)

> `.env` 는 git 에 올라가지 않습니다.
> 토큰은 **60일**이면 죽습니다. `토큰 연장` 워크플로가 매주 월요일 새 토큰을 로그에
> 남기니, 그것을 `IG_TOKEN` 시크릿에 다시 넣으셔야 합니다. 서버는 자기 시크릿을
> 스스로 못 바꿉니다.

## 무엇을 고치면 무엇이 바뀌나

전부 `config.json` 한 파일에 있습니다.

| 고치는 곳 | 바뀌는 것 |
|---|---|
| `account.handle` | 카드 왼쪽 아래 계정명 |
| `publish.perDay` | 하루 몇 편 (지금 3). 올리실 때는 `post.yml` 의 cron 주석도 푸십시오 |
| `publish.minGapHours` | 직전 게시와 최소 간격 |
| `video.secondsPerCard` | 카드 한 장이 머무는 초 (지금 4 → 총 11초) |
| `video.motion` | 천천히 확대되는 움직임. `false` 면 정지 화면 |
| `news.keywords` | 관심 낱말로 뉴스를 거릅니다. 비우면 전체 스포츠 |
| `write.model` | Gemini 모델. 이름이 바뀌면 `--models` 로 확인해 고치십시오 |
| `hosting.keepDays` | 영상을 며칠 남길지 (지금 14). 오래된 것은 지워 저장소를 가볍게 유지 |

**게시 시각**은 `.github/workflows/post.yml` 의 `cron` 입니다.
cron 은 **UTC** 라 한국시간에서 9시간을 뺀 값입니다 (21:30 → `30 12 * * *`).

## 손으로 돌려보실 때

```bash
npm install
npm run fonts
```

| 명령 | 하는 일 |
|---|---|
| `node scripts/news.js` | 오늘 뉴스 후보를 봅니다 |
| `node scripts/write.js --demo` | 가짜 뉴스로 원고를 뽑아 봅니다 |
| `node scripts/write.js --models` | 쓸 수 있는 Gemini 모델 목록 |
| `node scripts/photo.js "soccer stadium"` | 사진 한 장을 받아 `_photo.jpg` 로 저장 |
| `node scripts/render.js` | 카드를 그려 `_demo/` 에 저장 |
| `node scripts/video.js --probe` | ffmpeg 이 있는지 확인 |
| `node scripts/build.js --dry` | 만들어 보되 **파일은 쓰지 않습니다** |
| `node scripts/build.js --one` | **한 편만** 만들어 봅니다 |
| `node scripts/build.js` | 하루치를 만듭니다 |
| `node scripts/verify.js` | 게시 전 검사만 돌려 봅니다 |
| `node scripts/ig.js status` | 계정·오늘 진행 상황·토큰 상태 |
| `node scripts/ig.js queue` | **실제로 게시합니다** (되돌릴 수 없습니다) |

로컬에서 영상까지 만들려면 ffmpeg 이 필요합니다:
```bash
winget install Gyan.FFmpeg
```

## 알아두실 한계

- **소재가 3편 안 나오는 날이 있습니다.** 원고가 소재를 거르거나 사진을 못 찾으면
  그만큼만 나갑니다. 억지로 채우지 않습니다.
- **트렌딩 오디오를 못 씁니다.** 위 ①을 보십시오.
- **토큰 연장은 반쯤만 자동입니다.** 60일마다 한 번은 손으로 붙여넣으셔야 합니다.
- **댓글 응답은 없습니다.** 남의 계정 자동 좋아요·팔로우도 없습니다 —
  인스타 정책 위반이라 계정이 정지됩니다. 일부러 넣지 않았습니다.
- **하루 3편은 시작값입니다.** 새 계정이 갑자기 많이 올리면 노출이 눌릴 수 있어
  낮게 잡았습니다. 2~3주 돌려 보시고 반응이 괜찮으면 6편으로 올리십시오.
